2. Datenverarbeitung in der App

FoodStock verarbeitet folgende Daten ausschließlich lokal auf Ihrem Gerät:

  • Lebensmittelbestand (Name, Kategorie, Menge, Haltbarkeitsdatum)
  • Einkaufslisteinträge
  • Generierte Rezepte
  • Aktivitätsverlauf

3. Keine Weitergabe an Dritte

Alle Daten verbleiben auf Ihrem Gerät. Es wird keine Daten an Server, Cloud-Dienste oder Dritte übertragen, es sei denn, Sie aktivieren optional die Firebase Cloud-Sync.

4. Optionale Cloud-Sync (Firebase)

Wenn Sie die Cloud-Sync-Funktion aktivieren, werden Ihre Daten verschlüsselt an Google Firebase (Google LLC) übertragen. Dies unterliegt den Datenschutzbestimmungen von Google.

5. KI-Rezept-Generierung

Bei Nutzung der KI-Rezept-Funktion werden folgende Daten verarbeitet:

  • Gemini API (Google): Ausgewählte Zutaten und Präferenzen werden an Google Gemini gesendet zur Rezeptgenerierung.
  • Hermes Integration (optional): Daten werden an den von Ihnen konfigurierten Hermes-Agent-Endpunkt gesendet. Wenn dieser Agent ein lokales Modell nutzt, bleiben die Daten in Ihrem Netzwerk. Wenn der Agent einen Cloud-Anbieter nutzt, gelten dessen Datenschutzbedingungen.

6. API-Schlüssel

API-Schlüssel (Gemini, Firebase, Hermes) werden sicher auf Ihrem Gerät gespeichert. Bei aktivierter Cloud-Sync werden sie nicht in Google Backup gesichert.

7. Ihre Rechte

Sie haben das Recht auf:

  • Auskunft über gespeicherte Daten
  • Löschung aller Daten (App deinstallieren oder Daten löschen)
  • Deaktivierung der Cloud-Sync jederzeit
